# 📋 Projeto Pessoal — Frontend

Aplicação web pessoal desenvolvida para otimizar o dia a dia, reunindo em um único lugar módulos de controle financeiro, gerenciamento de tarefas e envio de notificações.

🔗 **Acesse:** [projeto-pessoal-frontend.vercel.app](https://projeto-pessoal-frontend.vercel.app/login)

---

## 🧩 Módulos

### 💰 Controle Financeiro
- Cadastro de movimentações de entrada e saída
- Gerenciamento de contas
- Criação de categorias personalizadas
- Gráficos de composição de gastos por categoria
- Gráficos de saídas do mês

### ✅ Tarefas
- Criação de categorias de tarefas
- Calendário semanal para adição e organização das tarefas
- Visualização por semana com marcação de tarefas como concluídas

### 🔔 Notificações
- Cadastro de e-mail e número de WhatsApp
- Criação de notificações personalizadas (recorrentes ou únicas)
- Envio automático nos canais configurados

## 🛠️ Tecnologias

- [Next.js](https://nextjs.org/)
- [TypeScript](https://www.typescriptlang.org/)
- [Chakra UI](https://chakra-ui.com/)

## 🌐 Deploy

O frontend está publicado na **Vercel** e consome o backend hospedado no **Railway**, que por sua vez utiliza o **Neon PostgreSQL** como banco de dados.

| Serviço  | Plataforma |
|----------|------------|
| Frontend | Vercel     |
| Backend  | Railway    |
| Banco    | Neon PostgreSQL |
